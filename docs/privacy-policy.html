Browser Toolkit プライバシーポリシー

最終更新日: 2026年11月25日

Browser Toolkit（以下「本拡張」）は、開発者（jey3dayo）が個人で開発・提供する Chrome 拡張機能です。本ポリシーは、本拡張が扱う情報とその利用方法を説明します。

基本方針

  • 本拡張は、開発者が運営するサーバーを持ちません。利用者の情報を開発者が収集・蓄積することはありません。
  • 解析ツール（アナリティクス）や広告のためのトラッキングは行いません。
  • 利用者の情報を第三者へ販売することはありません。

ブラウザ内に保存される情報

本拡張は、機能の提供のために以下の情報を利用者のブラウザ内（Chrome のストレージ）にのみ保存します。これらが開発者に送信されることはありません。

  • 設定、テキストテンプレート、検索エンジン・検索グループの定義（chrome.storage.sync / chrome.storage.local）
  • AI サービスの API キーなどの認証情報（chrome.storage.local に保存し、デバイス間では同期されません）
  • 直近に選択したテキストの一時キャッシュ（有効期限の目安は約30秒）
  • アクションの実行履歴

外部サービスへ送信される情報

外部へのデータ送信は、利用者が明示的にアクションを実行したときに限って発生します。

  • AI サービス（OpenAI / Anthropic / z.ai / ChatGPT）：Context Actions（要約・翻訳・コードレビューなど）を実行したとき、対象テキスト（選択範囲、なければページ本文）に加えて、ページのタイトルと URL がプロンプトの一部として、利用者が設定した AI サービスへ送信されます。API キーは該当サービスの認証にのみ使用されます。各サービスでのデータの取り扱いは、各サービスのプライバシーポリシーに従います。
  • Google Gemini：「Gemini で調べる」を実行したとき、選択テキスト（または対象リンク）とページのタイトル・URL を含むプロンプトが Gemini（gemini.google.com）へ自動入力・送信されます。
  • Google カレンダー：カレンダー登録を実行したとき、抽出されたイベント情報（タイトル・日時・場所・概要）を使って Google カレンダーの登録画面を開くか、iCal ファイルを生成します。

権限の利用目的

  • storage：上記の設定等をブラウザ内に保存するため
  • activeTab / scripting / ホスト権限（<all_urls>）：利用者が操作したページで、テーブルソート、選択テキストの取得、結果のオーバーレイ表示を行うため
  • contextMenus：右クリックメニューから機能を呼び出すため
  • alarms：認証情報の有効期限管理など、バックグラウンド処理の補助のため
  • notifications：処理完了などを通知するため
  • downloads：iCal ファイルなど、利用者が生成したファイルを保存するため
