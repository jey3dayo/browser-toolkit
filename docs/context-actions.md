# Context Actions（AI プロバイダー連携）

Context Actions は、設定中の AI プロバイダーを使って Web ページ上で実行できるアクション機能です。実行対象となるテキストは次のいずれかから決まります。

- 現在の選択範囲
- 直近の選択キャッシュ（ポップアップ実行時のみ。`chrome.storage.local` に保存し、同一オリジン・約 30 秒以内で参照）
- ページ本文（上記がない場合のフォールバック）

AI API へ送信される本文は、ここで決まった対象テキストです。選択範囲やキャッシュがない場合はページ本文（最大 20,000 文字）が送信対象となるため、機密情報を含むページで実行する際は選択状態を事前に確認してください。

## 実行経路

### 1. ポップアップ → アクション

- ページ上に選択範囲があれば、その選択範囲を対象にします。
- 選択範囲がなければ、同一オリジン上の直近の選択キャッシュ（有効期限の目安は約 30 秒）を使います。
- いずれも利用できない場合は、ページ本文にフォールバックします。

### 2. 右クリック → Browser Toolkit → アクション名

- 選択範囲の上で右クリックしてメニューを開いた場合は、その選択範囲を対象にします。
- それ以外の場合は、ページ本文を対象にします。

右クリックから実行したときは、ページから移動せずに確認できるよう、結果をページ上のオーバーレイで表示します。オーバーレイではコピー、ピン留め、ドラッグ移動、フォローアップ質問に対応しています。

## 組み込みアクション

既定のアクション（`src/context_actions.ts`）は `chrome.storage.sync` に保存され、ポップアップの「アクション」タブから編集・並び替え・リセットできます。

- 要約: 日本語で要点を箇条書きにまとめます。
- 日本語に翻訳: 対象テキストを自然な日本語に翻訳します。
- コードレビュー: 選択したコードやページ内容に対してレビュー観点を出力します。

カレンダー登録は独立した機能（ポップアップの「カレンダー」タブ、および右クリック → Browser Toolkit → カレンダー登録）として分離しています。ただし、カスタムアクションの種別に `event` を指定して独自のカレンダー抽出アクションを作成することもできます。

## カスタムアクション

ポップアップの「アクション」タブ（またはオプションページ）から独自のアクションを作成・編集・削除できます。

### 種別

- テキスト (`text`): 通常のテキスト結果を返します。
- イベント (`event`): 構造化されたイベントデータを返し、Google カレンダーの登録リンクおよび `.ics` ファイルの生成に使用します。

### テンプレート変数

プロンプト内では以下の変数を利用できます。

- `{{text}}`: 対象テキスト（選択範囲またはページ本文の抜粋）
- `{{title}}`: ページタイトル
- `{{url}}`: ページの URL
- `{{source}}`: 取得元（`selection` または `page`）

補足:

- プロンプトに `{{text}}` が含まれない場合は、拡張機能側で対象テキストを末尾に自動付与します。
- `{{title}}` と `{{url}}` のどちらも含まれない場合は、必要に応じてページのメタ情報を末尾に付与します。

## Event（カレンダー）抽出フォーマット

Event アクションおよびカレンダー登録では、モデルに JSON のみを返すよう指示し、以下のキーを扱います。

- `title`（string）
- `start`（string）
- `end`（string / optional）
- `allDay`（boolean / optional）
- `location`（string / optional）
- `description`（string / optional）

推奨する日時フォーマット:

- ISO 8601（例: `2025-01-31T19:00:00+09:00`）
- 難しい場合は `YYYY-MM-DD HH:mm` も許容
- 日付しか分からない場合は `YYYY-MM-DD` も許容

モデルが `start: "2025-12-16 14:00〜15:00"` のように開始・終了の範囲を 1 つのフィールドにまとめて返した場合でも補正を試みます。そのうえで Google カレンダーリンクと `.ics` ファイルを生成しますが、必要な情報が不足している場合は生成に失敗することがあります。

## 関連する設定

オプションページ →「設定」で以下を管理します（いずれも `chrome.storage.local` に保存され、デバイス間では同期されません）。

- AI プロバイダー: OpenAI / ChatGPT プラン / Anthropic / z.ai から選択
- 認証情報:
  - OpenAI / Anthropic / z.ai: プロバイダーごとの API トークンを設定
  - ChatGPT プラン: 「ChatGPT で続行」から Sign in with ChatGPT の OAuth サインインを実行（API キー不要）
- モデル: プロバイダーごとの対応モデルから選択
  - OpenAI / ChatGPT プラン: `gpt-6-luna`（既定）、`gpt-6.1-sol`
  - Anthropic: `claude-sonnet-5`（既定）、`claude-opus-5`、`claude-haiku-4-5`
  - z.ai: `glm-4.7`（既定）、`glm-5`、`glm-4.6`、`glm-4.5`
- 追加指示: 出力の口調や形式の好みを任意で上乗せ可能

モデルの検証（`src/schemas/provider.ts` の `normalizeAiModel`）では、各プロバイダーの対応済みモデル ID のみを受け入れます。設定が未指定または未対応の値だった場合は、読み込み時にプロバイダーごとの既定モデルへフォールバックします。保存値そのものの自動書き換えやモデル名ごとの変換は行わず、保存済みの対応モデルはそのまま使います。

## プライバシーと注意点

- AI プロバイダーへのデータ送信は、**アクションやカレンダー登録を明示的に実行したときだけ**発生します。
- 送信対象は、ポップアップ実行時は「選択範囲 → 直近の選択キャッシュ（同一オリジン）→ ページ本文」、右クリック実行時は「右クリック時の選択範囲 → ページ本文」の優先順で決まります。
- 直近の選択キャッシュと認証情報は `chrome.storage.local` に保存され、デバイス間では同期されません。
- 認証情報、秘密鍵、個人情報などの機密データを含むページやテキストで実行する際は選択範囲を確認してください。
