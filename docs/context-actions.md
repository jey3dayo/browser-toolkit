# Context Actions（AI プロバイダー連携）

Context Actions は、選択中の AI プロバイダーを使って Web ページ上でそのまま実行できる軽量なアクション機能です。実行対象となるテキストは次のいずれかから決まります。

- 現在の**選択範囲**
- 直近の選択キャッシュ（ポップアップからの実行時のみ。ローカル保存で有効期限の目安は約 30 秒）
- ページ本文（上記がない場合のフォールバック）

AI API へ送信される本文は、ここで決まった対象テキストです。選択範囲やキャッシュがない場合はページ本文全体が送信対象となるため、機密情報を含むページで実行する際は選択状態を事前に確認してください。

## 実行経路

### 1. ポップアップ → アクション

- ページ上に選択範囲があれば、その**選択範囲**を対象にします。
- 選択範囲がなければ、**直近の選択キャッシュ**（ローカル保存、有効期限の目安は約 30 秒）を使います。
- いずれも利用できない場合は、**ページ本文**にフォールバックします。

### 2. 右クリック → Browser Toolkit → アクション

- 選択範囲の上で右クリックしてメニューを開いた場合は、その**選択範囲**を対象にします。
- それ以外の場合は、**ページ本文**を対象にします。

右クリックから実行したときは、ページから移動せずに作業を続けられるよう、結果をページ上の**オーバーレイ**で表示します。

## 組み込みアクション

既定のアクションは `chrome.storage.sync` に保存されており、ポップアップから自由に編集・リセットできます。

- **要約**: 日本語で要点を箇条書きにまとめます。
- **日本語に翻訳**: 対象テキストを自然な日本語に翻訳します。
- **カレンダー登録する**: イベント情報を抽出し、以下の形式で出力します。
  - Google カレンダーの登録リンク
  - `.ics` ファイルのダウンロード（生成可能な場合）

## カスタムアクション

ポップアップから独自のアクションを作成・編集できます。

### 種別

- **Text**: 通常のテキスト結果を返します。
- **Event**: 構造化されたイベントデータを返し、カレンダー連携に使用します。

### テンプレート変数

プロンプト内では以下の変数を利用できます。

- `{{text}}`: 対象テキスト（選択範囲またはページ本文の抜粋）
- `{{title}}`: ページタイトル
- `{{url}}`: ページの URL
- `{{source}}`: 取得元（`selection` または `page`）

補足:

- プロンプトに `{{text}}` が含まれない場合は、拡張機能側で対象テキストを末尾に自動付与します。
- `{{title}}` と `{{url}}` のどちらも含まれない場合は、必要に応じてページのメタ情報を末尾に付与します。

## Event（カレンダー）抽出フォーマット

Event アクションでは、モデルに JSON のみを返すよう指示し、以下のキーを扱います。

- `title`（string）
- `start`（string）
- `end`（string / optional）
- `allDay`（boolean / optional）
- `location`（string / optional）
- `description`（string / optional）

推奨する日時フォーマット:

- ISO 8601（例: `2025-01-31T19:00:00+09:00`）
- 難しい場合は `YYYY-MM-DD HH:mm` も許容
- 日付しか分からない場合は `YYYY-MM-DD` も許容

モデルが `start: "2025-12-16 14:00〜15:00"` のように開始・終了の範囲を 1 つのフィールドにまとめて返した場合でも補正を試みたうえで、Google カレンダーリンクおよび `.ics` ファイルを生成します（必要な情報が不足している場合は生成に失敗することがあります）。

## 関連する設定

設定画面で主に以下の項目を扱います。

- OpenAI API Token: 必須（`chrome.storage.local` に保存され、同期はされません）
- Model: `gpt-6-luna`（既定）、`gpt-6.1-sol`
- 追加指示: 出力の口調やフォーマットの好みなどを上乗せできます

モデルの検証では、対応済みのモデル ID のみを受け入れます。設定が未指定または未対応の値だった場合は、読み込み時に共通の既定モデルへフォールバックします。保存値そのものの自動書き換えやモデル名ごとの変換は行わず、保存済みの対応モデルはそのまま使います。選択肢にない旧モデルが保存されている場合も、他の未対応値と同じフォールバック経路で処理します。

モデル ID と Chat Completions の対応状況については、OpenAI の [GPT-6 Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) / [GPT-6.1 Sol](https://developers.openai.com/api/docs/models/gpt-6.1-sol) ドキュメントを参照してください。

## プライバシーと注意点

- AI プロバイダーへのデータ送信は、**アクションを明示的に実行したときだけ**発生します。
- 送信対象は、ポップアップ実行時は **選択範囲 → 直近の選択キャッシュ → ページ本文**、右クリック実行時は **右クリック時の選択範囲 → ページ本文** の優先順で決まります。
- 直近の選択キャッシュは `chrome.storage.local` に保存され、デバイス間では同期されません。
- 認証情報、秘密鍵、個人情報などの機密データを含むページやテキストで実行する際は十分注意してください。
